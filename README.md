# signipv6

Sign timestamps and ipv6 durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/signipv6/

## Install / run

```bash
git clone https://github.com/theworker02/signipv6.git
cd signipv6
node src/cli.js
node --test
```
